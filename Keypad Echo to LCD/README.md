# Keypad Echo To LCD

[Repository overview](../README.md)

Show a decoded key on the LCD, then wait for its release before accepting another press.

## Implementations

Both entries use an encoder interface. One was recovered from a Proteus project. A malformed character literal in a draft needs attention before it can assemble.

| Implementation | Input | Output |
| --- | --- | --- |
| [Encoder Character LCD Output](Encoder%20Character%20LCD%20Output/README.md) | Keyboard encoder | LCD / serial by selected branch |
| [Proteus Encoder LCD Character](Proteus%20Encoder%20LCD%20Character/README.md) | Keyboard encoder | LCD / serial by selected branch |
