# Keypad Controlled LCD And Serial Output

[Repository overview](../README.md)

Use an encoder key to select a message and send characters to the LCD and serial interface.

## Implementations

The word-selection and transmit revisions differ in their branches and output sequences. Follow the example for the selected implementation rather than assuming every key behaves identically.

| Implementation | Input | Output |
| --- | --- | --- |
| [Encoder Serial Number Words](Encoder%20Serial%20Number%20Words/README.md) | Keyboard encoder | LCD / serial by selected branch |
| [Encoder Number Word Selector](Encoder%20Number%20Word%20Selector/README.md) | Keyboard encoder | LCD / serial by selected branch |
| [Encoder Number Word Transmit Revision](Encoder%20Number%20Word%20Transmit%20Revision/README.md) | Keyboard encoder | LCD / serial by selected branch |
