# Keypad And LCD Routines

[Repository overview](../README.md)

Provide support routines that scan a keypad and write characters or commands to an LCD.

## Implementations

This is a collection of support routines. A calling application is needed to decide what a key means and when to display a result.

| --- | --- | --- |
