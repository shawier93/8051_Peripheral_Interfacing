# 8051 Peripheral Interfacing

[Back to portfolio](https://github.com/shawier93/Projects-using-Assembly-for-8051)

Read physical inputs and pass characters between the processor, LCD, and serial interface.

## Applications

| Application | Description |
| --- | --- |
| [Keypad And LCD Routines](Keypad%20and%20LCD%20Routines/README.md) | Provide support routines that scan a keypad and write characters or commands to an LCD. |
| [Keypad Echo To LCD](Keypad%20Echo%20to%20LCD/README.md) | Show a decoded key on the LCD, then wait for its release before accepting another press. |
| [Keypad Controlled LCD And Serial Output](Keypad%20Controlled%20LCD%20and%20Serial%20Output/README.md) | Use an encoder key to select a message and send characters to the LCD and serial interface. |
| [Interrupt Driven Keypad Control](Interrupt%20Driven%20Keypad%20Control/README.md) | Respond to an external interrupt by decoding a key and sending the selected message. |
| [Switch Controlled Serial And Keypad Display](Switch%20Controlled%20Serial%20and%20Keypad%20Display/README.md) | Use two switches to select serial echo or keypad processing. |
